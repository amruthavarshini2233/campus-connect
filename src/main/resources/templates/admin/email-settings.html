Automated Registration Pass Template Preview

Every student event registration dispatches a multipart MIME message: an HTML university pass + plain-text fallback.

HTML Pass Features
  • Branded Header: CampusConnect college event pass branding with deep navy/indigo gradient.
  • Pass Identifier: Unique registration badge format CC-REG-{id}.
  • Event Details: Title, category, date, venue, student attendee name and roll number.
  • Ticket Check-in QR: Visual QR code placeholder with high-contrast scan border.
  • Security Watermark: Issue timestamp and verified student portal link.
Plain-Text Fallback Features
  • Guaranteed readability on minimal mail clients, smartwatch notifications, and accessibility screen readers.
  • Includes all critical pass metadata, venue details, and registration ID.
  • Direct link to student's portal at /my-registrations for one-click cancellation or status check.
